# ユーザーガイド

このガイドでは、Readeck モバイルアプリの基本的な使用方法について説明します。

## はじめに

1. **アプリのインストール**: Android または iOS デバイスにアプリをインストールします。
2. **ログイン**:
   - アプリを起動します。
   - Readeck サーバーの URL（例: `https://read.example.com`）を入力します。
   - ユーザー名とパスワードを入力します。
   - 「ログイン」をタップします。

## 機能

### ブックマークの管理

- **閲覧**: メイン画面にはブックマークの一覧が表示されます。スクロールして保存したコンテンツを確認できます。
- **読む**: ブックマークをタップすると、詳細なリーダービューが開きます。デバイス上で快適に記事を読むことができます。
- **編集/削除**: 詳細ビューや長押し操作（実装による）から、ブックマーク情報の編集や削除が可能です。

### 整理

リーディングリストを整理整頓しましょう：

- **ラベル**: ブックマークにラベルを付けて分類できます。
- **コレクション**: 関連するブックマークをコレクションにまとめることができます。
- **ナビゲーション**: ボトムナビゲーションやサイドメニューから、ラベルやコレクションの管理画面にアクセスできます。

### 高度な検索

探しているコンテンツをすぐに見つけることができます：

1. 検索画面に移動します。
2. キーワードを入力します。
3. 以下のフィルターを使用して絞り込みが可能です：
   - ラベル
   - コレクション
   - 追加日

### 共有（ブックマークの追加）

他のアプリから Readeck に直接コンテンツを保存できます：

1. Web ブラウザや他のアプリ（Twitter/X、ニュースアプリなど）を開きます。
2. 保存したい記事やページを表示します。
3. そのアプリの **共有 (Share)** ボタンをタップします。
4. アプリ一覧から **Readeck** を選択します。
5. Readeck アプリが一時的に開き、ローディングアニメーションが表示され、コンテンツが保存されると自動的に閉じます。
   - 保存に失敗した場合はエラーメッセージが表示されます。

### 設定

設定画面からアプリの挙動をカスタマイズできます：

- **テーマ**: ライトモードとダークモードを切り替えられます。
- **アカウント**: ログインセッションの管理ができます。
- **データ**: オフラインキャッシュやその他のデータ設定を管理できます。
